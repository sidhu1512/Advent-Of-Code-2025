# Advent of Code 2025

This repository contains my solutions for [Advent of Code 2025](https://adventofcode.com/2025), an annual set of programming puzzles. All solutions in this repository are implemented in **Java**, focusing on algorithmic efficiency, clean code practices, and optimal data structure selection.

## Repository Structure

The repository is organized by day. Each directory contains:
- The Java source code for Part 1 and Part 2 of that day's puzzle.
- A dedicated `README.md` explaining the approach, thought process, and a Time/Space Complexity (Big O) analysis for the solution.

*Note: Per the developer's request, puzzle inputs (`input.txt`) are not included in this repository. To run the code, you will need to provide your own input files generated by Advent of Code.*
